# pairwise-goap-planner

GOAP 计划器在前置条件里写 “HasAmmo”，世界状态里却是 “hasAmmo”，大小写不一致导致动作永远不满足；动作成本按静态表算，背包重量变化后仍选最便宜路线；目标已经达成时计划器还在找动作，NPC 原地循环；多个 NPC 共享一份计划缓存，一个人的背包状态污染整队；并行动作的效果顺序不确定，先加血还是先扣药随机；计划失败没有回退，NPC 卡在门口；感知更新与计划执行同帧竞争，刚看到敌人又按旧黑板行动；动作被中断后没有恢复原状态，锅里的菜永远半熟；搜索深度没有上限，复杂场景一帧卡死；存档只存当前动作不存计划队列，读档后从中间开始。gameplay/goap_planner.py 是核心，tests/test_goap_planner.py 15个红。要修的是：状态键规范化；成本按实时背包重算；目标已达成直接返回；计划缓存按 NPC 隔离；动作效果按声明顺序；失败回退到上一状态；感知与计划加锁；中断恢复快照；搜索深度上限；存档补计划队列。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
